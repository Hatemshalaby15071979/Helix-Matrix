Lesson 0024 — AI infrastructure: Ollama, LM Studio, Piper, Plotly, PyWebView/Tauri

Primary source: Ollama docs, Piper TTS, Plotly, Tauri.

Why this lesson

The AI infra layer is what makes local-first AI actually run: a model server (Ollama/LM Studio), TTS (Piper), charting (Plotly), and a desktop shell (PyWebView/Tauri). Each has a job; mixing them up wastes effort.

Concept

  • Ollama: local model server; runs LLMs on CPU/GPU; OpenAI-compatible API on localhost. AMD GPU needs Vulkan/ROCm build (not the snap on this machine).
  • LM Studio: desktop app for running local models; OpenAI-compatible server; good for experimentation.
  • Piper TTS: fast, local, multi-voice neural TTS; outputs WAV; voices are per-accent model files.
  • Plotly: interactive charts in Python (web + desktop); good for dashboards.
  • PyWebView / Tauri: desktop shells — PyWebView (Python + web view), Tauri (Rust + web view, smaller/faster). Both wrap a web UI as a desktop app.

Your machine: AMD RX 6700 XT (no NVIDIA); snap Ollama has no ROCm, so GPU inference runs via a user-level Ollama with OLLAMA_VULKAN=1 on port 11435 (48 tok/s, model fully in VRAM). 12 Piper voices installed (~756 MB). L&D Studio uses PyWebView-style local server + browser.
