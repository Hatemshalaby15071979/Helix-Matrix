Lesson 0012 — Erlang C forecasting

Primary source: Erlang C formula reference + Helix WFM engine (42 pinned tests).

Why this lesson

Erlang C is the staffing maths behind contact-centre forecasting: given call volume, AHT and target service level, how many agents do you need? It's the one formula every WFM professional must be able to derive and defend.

Concept

  • Inputs: call volume (per interval), AHT (seconds), target service level (e.g. 80% in 20s), shrinkage.
  • Erlang C: probability a call waits (Pw) given traffic intensity A and agents N. Derived via the Erlang B recursion (no factorials — numerically stable).
  • Service level: SL(t) = 1 − Pw · e^(-(N−A)·t/AHT) for t > 0.
  • ASA: average speed of answer = Pw · AHT / (N − A).
  • Agents needed: smallest N where SL(t) ≥ target.

Helix's WFM engine was rewritten onto the stable Erlang B recursion (N=5000 verified) after a non-standard closed form deviated 0.811 from the textbook probability of waiting. Pinned by 42 tests against reference values (0.5299 / 86.70% / 10.09s / 70.83% / 14 agents).
