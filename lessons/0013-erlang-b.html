Lesson 0013 — Erlang B

Primary source: standard teletraffic engineering texts; Helix WFM (uses B as the recursion base for C).

Why this lesson

Erlang B is the sibling of Erlang C: it gives the probability a call is blocked (lost) in a system with no queue (pure loss). Erlang C builds on it. Knowing both keeps you from confusing "waiting" with "blocked".

Concept

  • Erlang B (B): probability an arriving call finds all servers busy and is blocked/lost, in a loss system (no queue, Poisson arrivals, exponential service).
  • Recursion: B(0,A)=1; B(N,A) = (A·B(N-1,A)/N) / (1 + A·B(N-1,A)/N). Stable for large N.
  • Use cases: trunk sizing (how many lines), IVR ports, agent-less loss systems.
  • Relation to C: Erlang C uses Erlang B as an intermediate step to compute the probability of waiting in a queueing system.

Confusing B and C in a staffing model is a classic error: B assumes no queue (calls lost), C assumes an infinite queue (calls wait). Contact centres almost always use C.
