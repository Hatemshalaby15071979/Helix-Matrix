Lesson 0020 — Streamlit

Primary source: Streamlit docs.

Why this lesson

Streamlit turns a Python script into a web app with no front-end code. For ops tooling (dashboards, cockpits, internal tools) it's the fastest path from "I have a dataframe" to "a stakeholder can click buttons".

Concept

  • Rerun model: the whole script re-runs top-to-bottom on every interaction. State lives in st.session_state.
  • Widgets: st.button, st.selectbox, st.slider — each returns its current value.
  • Caching: @st.cache_data for data, @st.cache_resource for connections/models.
  • Layout: columns, tabs, expanders, sidebar.

Helix uses a Streamlit cockpit as a secondary, read-only diagnostic surface over the FastAPI spine. The cockpit is not the authority — the API is.
