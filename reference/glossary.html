Glossary

Compressed units of learning. Grows with each lesson.

A

awaiting_approval
Gate verdict: submission held because cost exceeds the acting role's approval limit; not executed.
audit ledger (hash-chained)
Append-only record where each entry's hash includes the previous entry's hash, so tampering breaks the chain.

D

dead_letter
Gate verdict: submission refused outright (unknown role, forbidden classification, non-owned engine, oversight-only seat). Engine not called.
deny by default
RBAC posture where any permission/classification not explicitly granted is treated as denied.

E

event sourcing
Persisting state as a sequence of immutable events; current state is a projection. (Lesson 0002.)
executing
Gate verdict: submission authorised and dispatched to the owning engine.

F

fail-closed
On missing input or missing authority, refuse to act rather than proceed with a permissive default.
fail-open
On missing input/authority, proceed with a permissive default — faster, usually wrong in safety-critical paths.

O

oversight_only
Role seat that proposes/reviews but never executes an engine; hard-denied regardless of target_engine.

R

RBAC (role-based access control)
Permissions attached to roles, not users; defaults to deny.
RoleSpec matrix
Helix's table mapping role → engines owned, classifications readable, financial limit, KPIs, oversight flag.

R (continued)

RAG (Retrieval-Augmented Generation)
Retrieve relevant passages from a corpus, then generate an answer conditioned on them. Confidence gate escalates on low margin.

S

Service Level (SL)
Probability a contact is answered within the target time (e.g. 80% in 20s).
Shrinkage
% of paid time an agent is unavailable for contact handling (breaks, training, absence). FTE = agents / (1 − shrinkage).
Streamlit
Python framework turning a script into a web app via rerun-on-interaction; state in st.session_state.

T

Tenant isolation
Guarantee that one tenant's data/actions/failures never leak into another's; enforced in the data layer.
Trivy
Vulnerability scanner for container images, filesystems and IaC.

W

WFM (Workforce Management)
Forecasting, scheduling, adherence, RTA, performance management for contact centres.
